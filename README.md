## 📁 About This Repository

This repository contains the full source code and advanced testing frameworks for EventMate:

- **`mobile/`**: Contains the mobile frontend application and dedicated E2E automation suites (`mobile-e2e-automation`, `flutter-e2e-automation`) using Appium.
- **`web/`**: Contains the web frontend, backend API, and web E2E automation suites using Selenium.
- **`.github/workflows/`**: Robust CI/CD pipelines configured to automatically provision environments (like Android Emulators) and run test suites on every push.

## 🚀 Getting Started

To run the automation tests locally:
1. Navigate to the desired automation directory (e.g., `cd mobile/mobile-e2e-automation`).
2. Run `npm install` to grab all dependencies.
3. Execute the tests using `npm run test`.
